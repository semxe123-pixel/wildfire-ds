**공통 기준 (2026-11-22)**: 설명서 표준 열 이름(`observed_at`, `available_at`, `station_id`, `bronze_file`, `admin_dong_code` 등) · 모든 시각에 한국 시간 표시(`Asia/Seoul`) · 요소마다 판정 열(`qc_TA` 등, 0 정상 / 1 결측 / 2 확인 필요 / 3 제거)과 걸린 규칙 열(`qc_TA_flags`) · `available_at` = 관측 + 1시간 · `src_file` · 규칙 문서 · 처리 건수 · 결과물 설명은 `data/silver/README.md`

**Silver에서 하지 않는 것**: 행정동 단위로 합치기, 후방 통계(24시간 평균 등), Feature–Label 붙이기, 빈 시각 채우기 → 전부 Gold

**순서 의존**: 1번은 변환표 없이 가능. 2·3번은 0번(변환표)이 있어야 한다. 2번은 행정동 경계도 있어야 한다.

**완료 기준** (설명서): 원천 값·변환 규칙·QC 결과·매핑 근거를 추적할 수 있고, 매핑 표(2번)와 Label 표(3번)가 독립 파일로 있을 것.

**기준 시점**: 발생·관측 시점에 유효한 행정동 코드표와 경계를 적용 (설명서 3절 "행정구역 기준"). 2026-07-01 행정구역 개편(인천·광주·전남·안양)으로 2026 체계와 코드가 다르므로, 2026 코드(관측소 LAW_ID 등)는 발생 시점 코드로 되돌려 써야 함.

## 기상 품질검사 규칙 (2026-11-23 확정, 24개월 적용)

**판정**: 0 정상 / 1 결측(기상청 -99) / 2 확인 필요(오류일 수도 진짜일 수도 있음 → 값 유지, 표시만) / 3 제거(물리적으로 불가능하거나 증거가 분명함 → 그 칸만 빈 값). WMO 품질관리의 suspect·fail에 해당. 여러 규칙에 걸리면 제거 > 확인 필요, 걸린 규칙은 모두 `qc_요소_flags`에 기록

**원칙**
- 실시간: 시각 t의 판정에는 t까지의 값만 씀 (다음 시각 값을 보면 예측 시점에 몰랐을 정보가 섞임)
- 이웃: 30 km 안에서 가까운 최대 3곳의 중앙값. 높이 차 제한 없음, 최소 1곳 (시험 1 민감도: 제한을 걸어도 판단 비율은 같고 판단 가능한 행만 줄어듦). 예외: 3-6은 높이 차 ±300 m
- 기온을 이웃과 수준으로 비교할 때는 높이 보정 (100 m당 0.65℃)
- 제거한 값과 기온 0.0 고착 값은 단계 규칙의 비교 대상에서 뺌
