# Silver 계획표 (2026-11-22 갱신)

**목표**: Bronze의 문자열 표를 → 계산 가능한 숫자 표로 바꾸고 → 모든 행이 행정동 코드로 이어질 수 있게 하고 → 바꾼 내용을 기록한다.
(기상 표에 행정동 열을 직접 붙이지 않는다. `STN → 행정동` 매핑 표로 Gold에서 잇는다.)

**모든 표에 공통으로 남길 것**: `src_file`(원천 추적) · `qc_*` 플래그 열(무엇이 걸렸나) · 규칙 번호가 적힌 문서 · 처리 건수

**Silver에서 하지 않는 것**: 행정동 단위로 합치기, 후방 통계(24시간 평균 등), Feature–Label 붙이기, 빈 시각 채우기 → 전부 Gold

**순서 의존**: 1번은 변환표 없이 가능(완료). 2·3번은 0번(변환표)이 있어야 한다. 2번은 행정동 경계도 있어야 한다.

**완료 기준** (설명서): 원천 값·변환 규칙·QC 결과·매핑 근거를 추적할 수 있고, 매핑 표(2번)와 Label 표(3번)가 독립 파일로 있을 것.

**기준 시점**: 발생·관측 시점에 유효한 행정동 코드표와 경계를 적용 (설명서 3절 "행정구역 기준"). 2026-07-01 행정구역 개편(인천·광주·전남·안양)으로 2026 체계와 코드가 다르므로, 2026 코드(관측소 LAW_ID 등)는 발생 시점 코드로 되돌려 써야 함.
