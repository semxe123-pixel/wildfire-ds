# Silver 계획표

**목표**: Bronze의 문자열 표를 → 계산 가능한 숫자 표로 바꾸고 → 모든 행에 행정동 코드를 붙이고 → 바꾼 내용을 기록한다.

| 순서 | 표 | 입력 → 출력 | 할 일 |
| --- | --- | --- | --- |
| 0 | 변환표 | 행안부 KIKmix + 국토부 전국법정동 → `adm_map` | 다운로드 → Bronze(원본·인덱스·구조화) → "법정동코드 → 행정동코드 + 유효기간" 한 표로 정리 |
| 1 | 기상 | `aws_raw` → `aws_silver` | 문자열→숫자 · 시각→datetime · `-99`→NaN · 범위 밖 값 플래그 · TA `0.0` 의심값 판정 · (STN,시각) 중복 검사 · 관측소별 결측률 · STN 집합이 관측소 목록에 포함되는지 |
| 2 | 관측소 매핑 | `stn_raw` + `adm_map` → `stn_to_adm` | STN → LAW_ID(2026) → 과거 법정동코드 → 행정동코드(발생 당시) · 위경도·지명으로 교차 검증 · 관측소 0개/2개 이상인 행정동 목록 |
| 3 | 산불 Label | `fire_raw` + `adm_map` → `fire_label` | 사건 키 생성·중복 검사 · datetime · 약칭→정식명 · 주소→법정동코드→행정동코드 · 피해면적 숫자화·단위 검증 · 매핑 실패 기록 |
| 4 | 검증 보고 | 위 4개 표 → `silver_report.md` | 표별 행 수, 결측률, 범위 이탈 건수, 매핑 성공률, 변환 규칙 목록 |

**모든 표에 공통으로 남길 것**: `src_file`(원천 추적) · `qc_flag`(무엇이 걸렸나) · 규칙 번호가 적힌 문서 · 처리 건수

**Silver에서 하지 않는 것**: 행정동 단위로 합치기, 후방 통계(24시간 평균 등), Feature–Label 붙이기, 빈 시각 채우기 → 전부 Gold

**순서 의존**: 1번은 지금 바로 가능. 2·3번은 0번(변환표)이 있어야 한다.

**완료 기준** (설명서): 원천 값·변환 규칙·QC 결과·매핑 근거를 추적할 수 있고, 매핑 표(2번)와 Label 표(3번)가 독립 파일로 있을 것.

**미결**: 행정동 코드 기준 연도 (발생 당시 vs 2026 현재) — 교수님 확인 중. 확인 전까지 발생 당시 기준으로 설계.

## 변환 규칙 (2025-03 탐색으로 확정, 건수는 24개월 적용 후 갱신)

| 규칙 | 대상 | 내용 | 근거 | 건수 |
| --- | --- | --- | --- | --- |
| R1 | TA WD WS RN_DAY RN_HR1 HM PA PS | 값 ≤ -99 → NaN | 기상청 결측 표시값(-99, -99.0). PA·PS 18.8%는 기압계 미설치 관측소 | |
| R2 | RN_HR1, RN_DAY | 값 < 0 → NaN, qc_neg_rain | 강수량 음수 불가. 센서 리셋 오류 (3월 13행, 최소 -12.5) | |
| R3 | PA, PS | 값 < 500 → NaN, qc_pa_invalid | 지상 기압 500hPa 미만 불가. 0.0 오류 (3월 3행) | |
| R4 | HM 0~100, WS ≥0, WD 0~360, TA -40~45 | 범위 밖 → NaN, qc_range | 물리적 범위. 3월 0건, 24개월 안전장치 | |
| R5 | TA | 같은 STN에서 0.0이 3시간 이상 연속 → NaN, qc_stuck_zero | 센서 고착값. 3월: 길이 1~2는 2,060구간(실제 0℃), 13~82시간 구간 5개(STN 415·770·230·622). 월 단위 처리라 월 경계에 걸친 구간은 분리 계산됨 | |
| R6 | 관측소 단위 | 24개월 결측률 > 50% → low_coverage (행 삭제 없음) | Gold 대표 관측소 선정 시 제외 근거. 3월: 337·339·340(96%), 659·915(57%) | |
| R7 | (STN, obs_time) | 중복 시 중단 | 설명서 "중복 처리", Gold 키 유일성. 3월 0 | |
